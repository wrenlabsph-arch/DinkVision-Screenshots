# DinkVision screenshot gallery

The root `index.html` displays **51 original APK screenshots** from DinkVision **0.5.43, build 49**, captured on November 5, 2026:

- **39 landscape screenshots** at 2560 × 1600.
- **12 portrait screenshots** at 1600 × 2560.

Open `index.html` in a browser after downloading this repository, or serve the repository root as a static website. Use the orientation selector to view landscape screenshots only. Category and text filters help find a particular screen. Click an image to open its full-resolution PNG. The gallery has no external assets or build step.

All PNG files referenced by the gallery are committed beside `index.html`. Keep them together when copying or hosting the gallery. `manifest.json` records filenames, screen labels, dimensions, and captured layout measurements. `.nojekyll` allows the files to be served directly by GitHub Pages when Pages is configured.

## Capture scope

These are screenshots of the APK UI on the API 35 Pixel Tablet emulator using isolated demo state. Recording, upload, connectivity, available camera modes, and update-policy screens illustrate their UI states; they are not proof of real camera performance, successful Google Drive transfers, email delivery, or the live required-update policy. Saved-video previews use the packaged placeholder, and playback was not verified during this capture run.

The test-clip review screen was excluded as requested. The capture run found no document overflow or modal panels outside the measured viewport. These screenshots do not replace testing on the presentation tablet and USB camera.

Only the gallery and its screenshots belong in this repository. It contains no APK, application source, enrollment codes, credentials, or original user recordings.
